## Hi, I'm Muntasir

I run **[AI Hustle World](https://aihustleworld.com)**, an independent publication about practical AI tools, prompt engineering and automation. I write guides that show their sources, and I publish the reusable parts of that work here as open data and open templates.

### Open projects

| Project | What it is | License |
|---|---|---|
| **[AI Tool Pricing Database](https://github.com/Muntasir-11/ai-tool-pricing-database)** | Open pricing data for AI tools. Every row links to the vendor page it was read from and shows the date it was last checked. | CC BY 4.0 |
| **[Prompt Engineering Toolkit](https://github.com/Muntasir-11/ai-hustle-world-prompt-toolkit)** | Reusable decision frameworks for prompting: context budgeting, system instructions, role prompting, structured output and more. | MIT |

Corrections are the most useful contribution to either project. Open an issue, and it will be checked against a primary source.

### How I work

Prices are read from the vendor's own page and dated, claims link to their source, and mistakes are corrected in the open. The details are in the [research methodology](https://aihustleworld.com/research-methodology) and the [corrections policy](https://aihustleworld.com/corrections-policy).
